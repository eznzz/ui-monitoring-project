# Monitoring Project — Mobile UI Audit

Проверка исходной реализации по HTML/CSS/JS и добавленный адаптивный слой `mobile.css`.

**Статус:** выполнена проверка исходного кода и внесены responsive-исправления. Полноценные тесты в реальных мобильных браузерах, проверка скриншотов и assistive technology **пока не проводились**, поэтому это не сертификат бездефектной адаптивности.

| Компонент | Обнаруженный риск | Исправление / текущее поведение |
| --- | --- | --- |
| Dashboard sidebar | Панель шириной 260px на мобильном экране | Уже существующий off-canvas до 900px; дополнено контролем прокрутки |
| Dashboard topbar / user menu | Недостаток места при 320–360px | Более компактные заголовок, кнопки, выпадающее меню |
| Dashboard карточки / формы | Мелкие отступы / переполнение | Адаптивные отступы и max-width |
| Catalog header / theme switch | Название и действия не помещаются | Скрытие второстепенного имени бренда, компактный переключатель |
| Catalog navigation | Много разделов и горизонтальное переполнение | Горизонтальная прокрутка меню, несклеиваемые пункты |
| Foundations / swatches | Четыре колонки на узких экранах | 2 колонки, уменьшение минимальной ширины |
| Buttons | Длинные тексты, малые touch-targets | Перенос подписей; на touch-устройствах мин. 44px |
| Text Fields | Непомещающиеся формы | Одна колонка на мобильных; контроли в пределах контейнера |
| Select | Переполнение контейнера | Ограничение max-width, адаптивная сетка |
| Checkbox | Мелкая область для нажатия | Строка не меньше 44px на touch |
| Data Table | Широкие столбцы на телефоне | Горизонтально прокручиваемый контейнер без потери столбцов |
| Search & Filters | Две колонки при узком экране | Полная ширина и вертикальное расположение |
| Sort / selection | Узкие ячейки | Таблица сохраняет min-width и скроллируется |
| Pagination | Кнопки и счётчик не помещаются | Вертикальное размещение футера, гибкий ряд кнопок |
| Tabs | Все вкладки могут не помещаться | Горизонтальная прокрутка с доступным фокусом |
| Modal Dialog | Длинное содержимое/низкий viewport | Max-height относительно `dvh`, внутренняя прокрутка |
| Toast | Выход за правую границу | Ширина ограничена viewport и отступами |
| Date Picker / Range | Пара полей не помещается | Адаптивная grid-form |
| Badge & Status | Длинные подписи | Перенос внутри доступной ширины, wrap контейнеров |
| Switch / Radio Group | Недостаточная высота области | Увеличенный touch-target, сохранены нативные inputs |
| Alert / Inline Validation | Длинное сообщение | Перенос текста, ширина ограничена контейнером |
| Tooltip | Может выходить за края экрана | **Требует последующего браузерного теста**; CSS не гарантирует управление позиционированием всплывающего слоя |
| Skeleton / Empty State | Фиксированные размеры | Контроль max-width и перенос |
| Charts: Line, Bar, Donut, Area | Графики не помещаются | Одноколоночная сетка, SVG масштабируется по ширине |
| KPI / Sparkline | Превышение размеров карточки | Ограничение ширины SVG и адаптивная сетка |

## Матрица ручного тестирования

Проверить страницы `/index.html` и `/components/index.html` в светлой и тёмной темах при ширинах **320, 360, 375, 390, 428, 768, 1024, 1440px**.

Минимальные сценарии:
1. Открыть закрыть sidebar, dropdown и переключить тему.
2. Проверить все состояния Buttons, Inputs, Select и Checkbox.
3. В Data Table выполнить поиск, сортировку, фильтрацию, выбор, перелистывание.
4. В Tabs проверить click и стрелки с клавиатуры.
5. Открыть Modal и закрыть Escape / Отмена.
6. Показать success/error/info Toast и закрыть вручную.
7. Проверить Date Range, Switch/Radio и inline validation.
8. Проверить все типы графиков и разворачивание таблиц данных.
9. Проверить горизонтальное движение вкладок и таблицы без горизонтальной прокрутки **всей** страницы.
10. Повторить с увеличенным текстом и Reduced Motion.

## Открытые задачи

- Браузерная визуальная регрессия в реальных viewport.
- Позиционирование Tooltip вблизи границ экрана.
- Сравнение тап-зон и контраста отдельных состояний с WCAG 2.2.
- Подтверждение работы mobile Safari, Chrome Android и экранной клавиатуры.
