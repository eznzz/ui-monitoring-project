# Monitoring Project — Mobile UI Audit

Проверка исходной реализации по HTML/CSS/JS и добавленный адаптивный слой `mobile.css`.

**Статус:** выполнена проверка исходного кода и внесены responsive-исправления. Полноценные тесты в реальных мобильных браузерах, проверка скриншотов и assistive technology **пока не проводились**, поэтому это не сертификат бездефектной адаптивности.

## Исправление Date Range и режим карточек (2026-10-12)

- Для нативных `input[type=date]` задаём `min-width:0`, `max-width:100%` и `box-sizing:border-box`; для сетки `.grid-form` на небольших экранах принудительно используем `minmax(0,1fr)`. Это устраняет типичный intrinsic-size overflow мобильных date-input.
- Data Table остаётся семантической таблицей на desktop и tablet; на экранах **до 600px** строки превращаются в карточки. Названия полей добавляются через `data-label`, формируются существующим рендерером таблицы.
- Поиск, фильтры, выбор отдельных записей и пагинация сохраняются. Для мобильного режима добавлен отдельный select сортировки, поскольку табличные заголовки в карточном режиме скрыты.
- Переключение вида на мобильных выполнено через CSS media query; отдельный источник данных для карточек не используется.
- **Нужна браузерная проверка** iOS Safari и Android Chrome, особенно native Date Picker, 320px ширины и озвучивания карточного представления экранными дикторами.

## Уточнение для iOS Date Range и радиуса карточек

- Карточки Data Table теперь используют общий `--vms-input-radius` (6px) вместо собственного скругления 12px.
- Date Range получил собственные классы `date-range-panel` / `date-range-grid`; на мобильных применяется вертикальный flex вместо CSS Grid, чтобы избежать intrinsic/min-content переполнения нативного date-input в WebKit.
- Нативный `input[type=date]` дополнительно ограничен `inline-size:100%`, `min-inline-size:0`, `box-sizing:border-box`; внутренний wrapper предотвращает визуальный выход за границу, а шрифт 16px исключает автоматический zoom iOS при фокусе.
- Следует повторно проверить Safari iOS на 320–390px и интерактивность системного календаря: статическая проверка CSS не подтверждает полное поведение на устройстве.
