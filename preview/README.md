# Preview — интерактивная версия Monitoring Project

Ветка `preview` создана отдельно от `main` и содержит текущий контрактный Platform UI прототип и лендинг `preview/index.html`.

## Маршруты
- `/preview/` — главная предпросмотра
- `/modules/platform/contract-demo/` — контрактный концепт Platform / Reviewer / Journal
- `/components/` — базовый каталог компонентов

## GitHub Pages
Публикация GitHub Pages проекта сейчас привязана к `main`. Нельзя менять источник публикации на `preview`, не оценив последствия для основного демо. Ветка `preview` — **источник готовой статической версии**, но сама по себе не создаёт второй сайт.

Для независимого постоянного публичного Preview требуются отдельная публикация (например, дополнительный сайт/репозиторий Pages, Pages workflow, сохраняющий main + preview, или другое статическое окружение). Не указывайте URL `github.io/.../preview/` как действующий, пока он не опубликован и не проверен.

## Правила
1. Только `eznzz/ui-monitoring-project` меняется; VDMS — read-only.
2. В Preview нет настоящих авторизации, паролей, TOTP, access token или SQL.
3. Для каждого этапа — отдельный PR, проверки Chromium и обновление Preview только после проверки изменений.
4. Структура API должна соответствовать версии `developerpiter/vdms` и документации; различия отмечаются явно.
5. Основную ветку не менять без утверждения.
