Первичный доступ

Без платных модулей компания может создавать пользователей и заполнять карточки выбранных типов объектов. Все модули включаются только платформой.

Лицензии выбранной компании

Каждый модуль оплачивается отдельно. После оплаты платформа выпускает ключ; компания отправляет запрос, который подтверждает суперадминистратор. Только затем модуль включается.

Граница ответственности

platform_db создаёт компании, назначает типы объектов, отмечает оплату и подтверждает заявки на активацию лицензий. tenant_db_* ведёт пользователей и базовые карточки назначенных типов объектов и может лишь направить запрос по ключу. Все данные демонстрационные.
