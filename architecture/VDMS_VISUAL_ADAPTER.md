# VDMS visual adapter

Both workspaces use the canonical Sidebar, Topbar, User Menu, content and theme script via frontend/shared/Shell.tsx. Existing tokens and styles are untouched. Original VDMS handlers and client models remain in source. Tenant user list, cards, tabs, modules and forms use the Monitoring Project components. Central navigation uses original permission filters. Central sample company names/status/revisions and partial C01 receipts/logs are based on user-provided screenshots, with generated identifiers and sanitized email transport. SMTP address and test environment identifiers are not copied. Reviewer invitation disabled as shown. Local diagnostics available; mail LAB hidden in this build. No actual backend operations. Browser checks are CI-gated; results must be verified before claiming parity.
